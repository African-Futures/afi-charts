# ISS Today Style Guide — Tableau

Transcribed from `Tableau ISS Today Style Guide.docx`. This is the institutional
guide for Tableau output. The D3 chart system diverges from it deliberately in
places — see `afi-chart-conventions-from-flourish.md` section 5 for the list and
the reasoning.

## Fonts

- Century Gothic
- Colour: black
- Worksheets: black, 9 pt

## Lines

- Gridlines: `#f5f5f5`
- X-axis: `#555555`, solid, thinnest option
- Ticks: `#555555`, major ticks only
- Y-axis: not shown

## Palette

```
#172859  #004ea2  #389d63  #d1d2d4  #58585a  #213f7f
#5791cd  #5cba60  #eff0f1  #b72325  #8c1d1b  #eaa22f
#f58220  #660066  #e6cf98  #7f0f3b  #8064a2
```

Seventeen colours. Only seven sit inside the usable lightness band with enough
chroma to do identity work, which is why the D3 series ramp snaps three of them
— see the conventions doc, section 7.
